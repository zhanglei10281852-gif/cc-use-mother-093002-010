# 国际中文教师三维认证

面向国际中文教育学院的教师三维能力（语言能力、教学技能、跨文化素养）认证服务。
管理带版本的能力框架、观察任务、证据材料与评委资质，支持独立评分、利益冲突申报、
评分偏离校准与外部复核，形成通过 / 附条件通过 / 补强后复评 / 不通过四类决定，
并跟踪补强计划与证书签发。

## 结构

- `framework.py` — 维度、指标、决策政策与带生效区间的框架版本；新版本发布自动关闭上一版本的开放区间
- `evidence.py` — 观察任务与证据材料（课堂观察 / 学术成果 / 实践反馈），证据必须归入框架指标
- `scoring.py` — 独立评分表（评分期密封）、利益冲突申报、偏离识别与三维加权汇总
- `calibration.py` — 偏离指标的校准会话与外部复核裁定
- `decision.py` — 认证决定；复评决定必须引用原决定与新增证据
- `remediation.py` — 补强计划：步骤前后依赖（无环）、完成期限与导师确认
- `certificate.py` — 证书；同一候选人至多一张有效证书
- `case.py` — 案件状态机（立项→评分→校准/复核→待决定→已决定→结案）与评分轮次
- `service.py` — 应用服务，编排全部用例；单仓储锁内完成变更并即时落盘
- `store.py` — JSON 文件仓储，原子写；服务重启后待校准等中间状态保持原样
- `queries.py` — 评审秘书时点查询：当时有效的决定、三维差距、校准过程、未完成补强步骤
- `contracts.py` — 初始基础契约（保留）

## 关键规则

- 评委组合的资质须覆盖三个维度且每维度至少两人；评委只能给资质范围内的指标评分
- 评分前必须申报利益冲突；有冲突的评分表自动排除出汇总
- 指标评分极差超过阈值自动进入校准；校准不收敛则转外部复核，复核人须未参与本案评分
- 过期框架版本不能签发新结论，也不能签发证书
- 复评必须引用原决定并附晚于原决定日期的新增证据
- 附条件通过须完成全部补强步骤方可发证；补强后复评须完成补强才能开启新一轮评分
- 证书签发在锁内检查并插入，并发操作不会产生两张有效证书
