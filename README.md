# 国际中文教师三维认证

面向国际中文教育学院的教师三维能力认证服务，覆盖语言能力、教学技能、
跨文化素养三个维度，解决分散记录、评委尺度差异与延期认证溯源问题。

## 领域结构

```
src/teacher_certification/
  model.py        领域模型：带版本的能力框架、观察任务、证据、评委、
                  评分表、利益冲突申报、校准会话、认证决定、补强计划、证书
  service.py      应用服务：全流程业务规则与评审秘书 as-of 快照查询
  repository.py   持久化：内存仓库 / JSON 文件快照仓库（原子写）
  codec.py        类型导向的 JSON 编解码
  errors.py       领域错误类型
  contracts.py    早期基础契约（保留兼容）
```

## 核心规则

- **能力框架带版本**：框架按版本发布，含三维指标与维度合格线、生效/失效
  窗口；过期或已停用的框架不能签发新结论。
- **证据归入指标**：课堂观察（由观察任务产出）、学术成果、实践反馈三类
  证据必须挂到案件所用框架版本的指标上。
- **独立评分与利益冲突**：评审组至少两名评委且可评维度覆盖三维；评分表
  须覆盖全部指标；申报利益冲突的评委立即回避，其评分不计入汇总。
- **评分偏离识别**：同一指标上评委评分极差达到阈值（2.0）即转入待校准；
  校准修订后仍有偏离则转复核，由复核人裁定争议指标。
- **四种认证决定**：通过 / 附条件通过 / 补强后复评 / 不通过。任何维度
  低于合格线都不能「通过」——单项高分不能掩盖真实课堂暴露的短板；
  决定必须写明理由。复评决定必须引用原决定并附原决定之后的新增证据。
- **补强计划**：步骤有前后依赖（无环校验）、完成期限（逾期拒绝登记）
  与指定导师确认；全部确认后案件自动进入待复评。
- **证书唯一**：同一候选人至多一张有效证书；签发在单锁内完成，
  并发操作不会产生两张有效证书。
- **秘书快照**：`certification_snapshot(候选人, 查询日期)` 返回当时有效
  的认证决定、三维差距、评委校准过程与尚未完成的补强步骤。
- **状态可恢复**：每次变更即时落盘（JSON 快照），服务重启后待校准案件
  等中间状态保持不变，可继续推进。

## 运行

运行测试：

    python3 -m unittest discover -s tests -v

编译检查：

    python3 -m compileall -q src tests run_cli.py

命令行冒烟（完整流程演示 + 秘书快照）：

    python3 run_cli.py
